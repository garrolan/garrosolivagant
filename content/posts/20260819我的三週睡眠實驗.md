7月底從羅馬尼亞回到台灣之後，我的睡眠開始變得有點奇怪。

一開始當然很好解釋。羅馬尼亞和台灣夏季有五個小時的時差，7月31日剛回國，我晚上八點多先睡了兩個多小時，半夜醒來之後開始跟GPT聊天、看文章、聽得到APP。00：55我還告訴自己該睡了，01：15卻又起床擦藥，發現好像還是睡不著，甚至在日誌裡留下「焦慮到難以入睡」這句話。後來01：29乾脆泡咖啡，正式開始新的一輪活動。

但我很快發現，時差大概只解釋了最前面的一小段。真正麻煩的，是我剛好在這個時間點接任教導主任。7月31日走進學校、整理新座位，8月1日開始翻前任留下來的硬碟與交接資料，主任這個原本還有點抽象的新身分，突然變成一大堆公文、經費、行事曆、活動、學生事務、教師研習和我根本還不知道自己不知道的東西。

<!--more-->

## 從回國時差，到主任工作的高警覺

8月2日凌晨，我曾經很明確地寫：

> 我這幾天，是不是被「應該要做好主任工作」這個念頭給劫持了？

那陣子的狀況，其實已經不只是「工作很多」。

我會不停翻交接資料、查硬碟、盤點行政業務，腦中一直跑著：「會不會還有什麼我不知道？」「開學之後突然出事怎麼辦？」「我是不是應該趁現在再多準備一點？」

每完成一項工作，確實會短暫安心一下，可是工作本身又會長出新的工作。主任業務涵蓋的範圍太廣，我如果把「全部弄懂」當成可以休息的前提，那個停止條件根本不存在。

睡眠就成了很誠實的反應。

8月1日其實睡得很好，04：31鬧鐘響才醒，中間沒有醒來。8月3日更完整，大約20：40睡著，一路睡到04：30，接近八個小時。

8月6日也曾經03：15醒來，自己判定「倒是一次睡到底，有比較進步了」；8月12日則大約18：40就睡著，一路睡到02：22，七個多小時沒有中斷。

所以我的睡眠系統並不是突然壞掉了。

麻煩的是，這種完整睡眠在八月上半月反而成了少數。

## 把「睡不好」拆開來看

到了8月16日，我終於決定不要再只靠感覺說「最近好像睡不好」，而是把8月1日至15日的日誌全部拉出來重新盤點。

結果比我原本想像得清楚很多。

| 8/1～8/15睡眠型態 | 天數 | 比例 |
| --- | ---: | ---: |
| 明確一覺到底 | 4天 | 26.7% |
| 明確半夜醒來、之後又睡 | 9天 | 60% |
| 很早醒來後直接開始一天 | 2天 | 13.3% |

15天裡面，只有4天能夠明確判定為一覺到底。

反而有9天留下了半夜醒來、後來再睡的紀錄。

而且時間並不固定：

- 8月4日大約00：35醒來，當時懷疑有點熱。
- 8月5日大約22、23點就醒過一次。
- 8月7日23：40左右醒來，後來又開始想工作。
- 8月8日00：36醒。
- 8月10日00：59醒。
- 8月11日中間醒來，01：15再睡，03：58又醒。
- 8月13日01：43醒。
- 8月14日02：02醒。
- 8月15日晚到16日清晨，更直接切成好幾段。

也就是說，我模糊感受到的「睡不好」，拆開之後其實有一個相當明顯的模式：我大多睡得著，問題發生在睡著以後，睡眠很容易被切斷。

我暫時把它稱作「睡眠連續性問題」。這只是我根據生活日誌做的描述，不是什麼醫療診斷。

## 更有趣的是：我半夜醒來之後都在幹嘛？

這可能是整次盤點最好笑的地方。

別人半夜醒來，也許就是翻個身、上個廁所，再躺回去。

我的日誌卻忠實記錄著：

醒來。

聽得到APP。

看文章。

跟GPT聊天。

想到一個問題，開始研究。

突然想起某項工作，又去查資料。

有時候甚至乾脆起床泡咖啡。

換句話說，我的夜間問題不只是「醒來」，而是**一醒來就很容易正式開機**。

8月上旬主任工作的焦慮尤其明顯。白天遇到的不確定性，到了晚上好像仍然在大腦後台繼續運算；半夜一醒，那些工作、疑問、資訊就重新浮出來。

我開始列出幾個可能的影響因素。

| 可能因素 | 當時看到的線索 |
| --- | --- |
| 接任主任的工作焦慮 | 不確定性很多，白天與夜間都有工作反芻 |
| 夜醒後進入高認知活動 | 音頻、閱讀、AI聊天、查資料 |
| 3C產品與資訊刺激 | 睡前、夜醒後都很容易繼續使用 |
| 冷氣、溫度與風感 | 有時太熱，有時又覺得冷風吹身體不舒服 |
| 午睡 | 懷疑白天睡多了會不會影響夜晚 |
| 剛回國的時差 | 7月底很合理，但到了8月中旬解釋力已經愈來愈低 |
| 晨間散步與日照 | 我也開始懷疑它可能影響作息，但手上的日誌還不足以判斷 |

問題列出來了，接下來就可以做點小實驗。

## 8月16日：關掉電腦，找一件不需要想太多的事情

8月16日是星期日。

那天下午我其實有午睡，14：11睡到15：23，大約72分鐘。所以後來那晚睡得好，不能簡單歸因成「白天完全沒睡，晚上累垮」。

晚餐之後，我開始刻意降低資訊量。

18：49左右，我把電腦關掉。

接下來既沒有繼續聽音頻，也沒有播放音樂，而是找了手縫的東西來做。縫褲管、縫布料，針穿過去、線拉回來，一針一針慢慢處理。

這種活動跟我平常用電腦做事情很不一樣。

查一份公文，很可能會想到另一項經費；看一個資料，又會發現另一個疑問；跟AI討論一件事，常常可以在半小時之內長出十個支線。

手縫幾乎沒有這種問題。

我只需要處理眼前那一針。

更重要的是，到了20：01左右，我並沒有逼自己一定要把它縫完。我看著做到一半的東西，覺得今天差不多就這樣，於是收起來。

「做到哪算哪。」

這件事後來回頭看，我覺得甚至比手縫本身還重要。

那天晚上20：35左右關燈，一路睡到隔天03：06。

連續6小時31分鐘。

加上下午72分鐘午睡，24小時內至少睡了7小時43分鐘。

我8月17日清晨醒來時，自己寫下：

> 感覺一覺到底，可能昨晚睡前少用3C產品有幫助？比較有休息到的感覺。

第一場實驗，效果看起來很好。

## 但是日誌很快抓到我的「人類幻覺」

問題是，我很快就差點太早下結論。

8月17日清晨，我回想前一晚，覺得自己「幾乎都沒有使用手機」，於是開始懷疑：會不會真的是因為少了藍光、少了3C，所以睡得特別完整？

結果回頭翻即時記錄才發現：

20：06，我還拿手機問GPT為什麼《海底總動員》的小丑魚叫Nemo。

20：09，我聽了《龐加萊猜想》的聽書。

20：28，我甚至還問了千禧年七大數學難題。

所以，我記憶中的「昨晚幾乎完全沒有用手機」，其實並不準確。

這件事很好笑，也讓我更加相信平常那些瑣碎得要命的即時日誌真的有用。

人腦會自行美化、壓縮、重組自己的記憶。幾天後再回想，很容易覺得：「啊，我那天就是完全沒看手機，所以睡好了。」

實際資料卻不是這樣。

於是第一個過於簡單的假說被修正了。

真正值得注意的，也許沒有簡單到「碰手機就睡不好」。我開始把焦點轉向整體的**認知負荷**：晚上有沒有繼續搜尋、分析、決策、規劃？腦袋有沒有不斷生成下一件事情？

8月16日晚間雖然仍然碰過手機，但大部分時間都在低資訊量的手縫活動裡，而且沒有追求完成。

這可能才是比較重要的地方。

## 8月17日：電腦關掉了，生活卻突然空了一塊

第二晚我試著繼續。

8月17日晚上19：15，我就把電腦關掉了，甚至一度把小紅書APP卸載。

可是那天沒有手縫。

接著我發現另一個以前沒有特別注意過的問題：

**電腦關掉以後，我要幹嘛？**

工作當然大部分都在電腦上。

可是自由人生實驗室也常常是電腦。

閱讀文章、整理生活、跟AI討論、寫作、做網站、研究工具，很多我真正喜歡做的事情，這幾年同樣高度數位化。

白天已經盯著螢幕工作那麼久，晚上眼睛不想再看電腦，等於同時把工作和一大部分興趣一起切斷。

所以8月17日晚上的實際情況，沒有前一天那麼漂亮。

我雖然早早關了筆電，後來還是改成使用手機、聽東西、聊天。19：49日誌寫著「準備休息」，但我沒有找到像手縫那樣可以自然待在裡面的活動。

那天我甚至冒出一種有點空洞的感覺：

> 扣除掉工作，我就沒什麼生活重心的感覺？

這個問題其實比睡眠本身更讓我在意。

我當然不是沒有興趣。我喜歡閱讀、散步、手作、寫東西、旅行、亂想很多問題，也喜歡跟GPT討論。

只是這些興趣裡面，很多現在都綁著螢幕。

這讓第二晚的睡眠實驗多了一個新的問題：如果只是叫自己「不要工作、不要看電腦」，留下來的會不會只是一大片空白？

即使如此，隔天8月18日03：11第一次醒來時，我仍然判定自己算是一覺到底。

而且03：25之後還明顯想睡，繼續躺著，到04：04才「再次醒來」，04：27才真正起床。

第二晚沒有完全複製第一晚的方法，睡眠連續性卻仍然維持住了。

事情開始變得更有意思。

## 8月18日：五本書、88分鐘午睡，還有一通晚間工作電話

8月18日下午，我去了一趟圖書館。

13：52抵達，13：59到二樓借書，最後一共借了5本。

我當時的想法其實很單純：

> 早點借書，晚上不會沒事做。

這句話正好回應了前一天晚上那個「關掉電腦以後要做什麼」的空白。

但人就是這樣，借書的當下總覺得自己會看，借回家之後又不見得真的有動力。

而且那天下午還發生另一件很不利於「晚上好好睡覺」的事情。

15：25我躺床上想小睡，還覺得好像睡不著，15：42甚至起來翻了一下《非人哉》。結果16：00真的睡著之後，直接一路熟睡到17：28鬧鐘響。

整整88分鐘。

而且是下午四點才開始睡。

如果午睡真的是我夜間睡眠破碎的主要兇手，那一天理論上應該非常危險。

可是晚上，我沒有特別執行什麼複雜的睡前儀式。

我一邊吃那碗硬得要命的紅豆剉冰，一邊隨手翻一本日本人CHIKA寫的《芬蘭熱愛100選》。那不是什麼認真閱讀，我也沒有做筆記，只是想到哪看到哪。

翻到八點多，慢慢覺得有些睏了，就準備關燈上床。

這正是我想找的那種替代活動。

不需要產出。

不需要學會什麼。

不需要讀完。

甚至一本書看到十頁不想看了，換一本也無所謂。

只是讓晚上有一件事情可以自然地做。

## 那通晚上八點多打進來的工作電話

8月18日晚上還出現了一個意外的測試。

文具店的廠商打電話給我，確認一份學校訂單的資料。

對方的語氣還略有些不悅。

我當然也有情緒。

我明明就是按照網站上的資訊做採購，如果價格調漲卻沒有標註，難道是我的錯嗎？

而且我花錢採購，怎麼搞得好像還要受氣？

合作本來就是雙向的。一次可以，幾次都是這樣的態度，我也沒有非得一直跟同一個單位合作。

但真正值得記錄的，是我那天沒有因為這通電話立刻打開電腦做處理。

我把問題記下來，決定：

**明天到學校再處理。**

這件事情放在八月初的我身上，可能會完全不一樣。

那時候只要碰到一個不確定，我就很容易想：「先確認一下好了。」

然後查訂單。

看網站。

翻經費。

問AI。

思考明天要怎麼回。

一個原本五分鐘可以結束的工作電話，就這樣一路把整個晚上重新拖回工作狀態。

8月18日這一次，我第一次很清楚地感覺到：

我可以知道這件事情存在。

我甚至可以不高興。

可是我不用現在處理。

因為晚上八點多，對我的生活節律來說，本來就已經是準備睡覺的時間。

事情可以明天再說。

結果8月19日03：06醒來，又是一次一覺到底。

我自己估算大約睡了六個小時。那晚開著窗，沒有開電扇，也沒有開冷氣；一直到03：36起床後，看到室溫已經29度，我才把冷氣打開。

第三晚，主要睡眠仍然沒有碎裂。

## 三晚的小實驗，暫時得到什麼？

把8月16日至18日三個晚上放在一起，條件其實並不完全相同。

| 夜晚 | 睡前主要狀態 | 午睡 | 夜間結果 |
| --- | --- | --- | --- |
| 8/16→8/17 | 關電腦、手縫、幾乎不聽音頻、不追求完成 | 72分鐘 | 20：35→03：06，連續6小時31分鐘 |
| 8/17→8/18 | 19：15關電腦，但仍用手機、聽音頻、聊天 | 有午睡 | 03：11第一次醒，主要睡眠完整，之後很可能又睡了一段 |
| 8/18→8/19 | 隨性翻紙本書，工作電話延後到隔天處理 | 16：00→17：28，88分鐘 | 約6小時，03：06醒，一覺到底 |

實驗前的8月1日至15日，15天裡只有4天能夠明確判定為一覺到底，比例大約26.7%。

實驗的三個晚上，主要睡眠都維持完整。

三晚當然太少了，完全不能拿來證明因果，也不能說我就此找到什麼改善睡眠的標準答案。

但是從我自己的生活紀錄來看，這已經足夠支持一個暫時判斷：

**晚上降低認知負荷這個方向，值得保留。**

而且它不像我最初想像得那麼狹窄。

不需要完全禁止手機。

也不一定要每天手縫。

真正有幫助的東西，看起來更接近：不要讓晚上持續長出新的任務與決策。

手縫很好，因為它只有眼前的一針。

隨性翻紙本書也很好，因為不用讀完，不用寫心得。

工作電話打進來，我可以記下來，明天再處理。

甚至一件手作做到一半，也可以就停在那裡。

## 幾個原本的嫌疑犯，也重新排了一次順位

這次實驗之後，有些假說還留著，有些則被我暫時降級。

| 原本的假說 | 目前的暫時判斷 |
| --- | --- |
| 接任主任的焦慮與工作反芻 | 仍然是很重要的背景因素 |
| 晚間高認知負荷 | 目前最值得注意 |
| 夜醒後立刻開始閱讀、思考、工作 | 很可能會把短暫覺醒延長 |
| 完全禁止3C才能睡好 | 目前資料不支持這麼簡單的說法 |
| 午睡造成晚上睡不好 | 至少目前不像主要因素，72分鐘與88分鐘午睡後仍然睡得完整 |
| 冷氣決定睡眠品質 | 會影響舒適度，但8月18日晚完全沒開冷氣仍然一覺到底 |
| 手縫有沒有幫助 | 很有希望，但可能不是因為「手縫」本身，而是低決策、低資訊、可隨時停下 |
| 紙本閱讀有沒有幫助 | 第一次測試結果不錯，適合填補關掉電腦後的生活空白 |
| 每件工作都要立即處理 | 這反而可能是我真正需要鬆動的習慣 |

另外，我也開始懷疑早晨散步與戶外日照會不會影響睡眠節律。

8月18日早上06：36，我就在北山里小徑散步，沿途看水田、白鷺鷥、田埂上的八哥和一顆很大的絲瓜。最近幾週我也常在清晨出去走路。

不過這一項我的日誌沒有每天精確記錄出門時間、日照強度和持續多久，所以現在還不足以跟睡眠品質做可靠對照。

先知道它可能存在就好。

這一次不繼續往下挖。

## 03：06、03：11、03：06

三晚實驗結束之後，又冒出一個很好笑的新問題。

8月17日第一次醒來：03：06。

8月18日：03：11。

8月19日：03：06。

三天最大差距只有五分鐘。

我一直以為自己的生理時鐘大約是04：30起床。照原本的理想狀態，20：30睡、04：30起床，剛好八小時；就算21：00才睡，也還有七個半小時。

現在如果總是在03：00左右醒，即使一覺到底，夜間睡眠很容易只剩六個多小時。

這到底代表什麼？

是最近生理時鐘又往前移了？

還是前半個月碎裂睡眠之後，身體仍然需要補眠，只是清晨太容易醒？

晨間日照有沒有影響？

為什麼8月18日03：11醒來以後，我還明明很想睡，甚至03：25躺回去，04：04才再次醒來？

這些都是可以繼續研究的問題。

但我決定先停。

因為才剛說不要把睡眠變成KPI，結果一發現睡眠連續性改善，我跟GPT馬上又開始討論：「那總時數是不是也要七小時以上？」

很好。

睡眠績效考核第二階段差點立刻開辦。XD

## 這一波實驗，先到這裡

回頭看這三週，我最初只是覺得「最近好像睡不好」。

後來翻日誌，才把這句話拆成比較具體的現象：

入睡通常沒有太大問題。

八月上半月的主要狀況，是半夜容易醒。

而且一旦醒來，我很容易重新進入高認知負荷的狀態。

工作焦慮當然有影響，尤其剛接任教導主任那幾天，我的大腦幾乎一直試圖消滅未知、提前處理、提早準備。

可是到了8月中旬，我開始試著做另一件事情。

晚上關電腦。

找手縫。

隨便翻紙本書。

允許東西做到一半。

一通八點多打進來的工作電話，可以放到明天。

我不需要證明自己完全不碰手機，也不用建立一套精密的睡前流程。

至少這三個晚上，我真正改變的，是晚上對事情的反應方式。

如果有一件事情最值得我從這次睡眠實驗留下來，大概就是8月18日晚上的那個選擇：

**我知道這件事了，但我明天再處理。**

這其實跟睡眠沒有那麼遠。

我最近一直在學習怎樣做一個教導主任，同時也一直在學另外一件看起來更簡單、實際上更難的事情：

工作做到哪裡算今天結束？

什麼事情可以暫時不知道？

什麼事情可以明天再做？

到了晚上，我還能不能把自己的時間拿回來？

8月19日清晨寫隨筆時，我最後真正關心的問題已經變成：

> 我怎樣才能健康？才能夠有餘裕？才能夠更愜意自如？

睡眠只是其中一部分。

這三晚也沒有證明我已經找到答案。

但至少，在接任教導主任之後那一段幾乎停不下來的日子裡，我開始重新練習一件事情：

到了晚上，世界當然還會繼續運轉。

可是我可以先下班。
